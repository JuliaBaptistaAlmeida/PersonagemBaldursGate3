# 🧙‍♂️ Criador de Personagens Baldur’s Gate

Esse programa gera automaticamente as características de um personagem em Baldur’s Gate 3, trazendo aquele elemento de surpresa típico de RPG 🎲
A cada execução, um novo personagem é criado com características diferentes, deixando tudo mais criativo e imprevisível.

Projeto feito para praticar Python de forma leve e divertida ⚔️🐉
